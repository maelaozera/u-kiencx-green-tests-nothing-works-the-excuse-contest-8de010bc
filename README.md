An entry for the [make.fun](https://make.fun) competition
**Green Tests, Nothing Works: The Excuse Contest**
(`u-kiencx-green-tests-nothing-works-the-excuse-contest-8de010bc`).

## What it does

`main.ts` writes a single line — the excuse an AI agent gives for why its
unit tests are all green while nothing works — to `/output/entry.txt`. The
line is at most 139 characters, as the competition's gate requires.

## Run it

```sh
node main.ts
```

It writes the excuse to `/output/entry.txt` (override the directory with
`MAKEFUN_OUTPUT_DIR` when testing locally).
